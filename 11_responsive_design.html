Responsive units

16px — fixed size, never changes

1rem — follows the root font size

4vw — grows/shrinks with the window (resize me!)

clamp(1rem, 2.5vw, 2rem) — fluid but never too small/big

Responsive image

max-width: 100%; height: auto; — the two lines that stop images breaking mobile layouts.

Key takeaways: viewport meta is mandatory; design mobile-first; use clamp() for fluid type; test by resizing.
