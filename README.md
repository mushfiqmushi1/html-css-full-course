# HTML & CSS: Full Course 🎨

Learn HTML and CSS from zero to building real responsive pages.
Every file is self-contained — just **double-click it** and it opens in your browser.

## Learning path

| # | File | What you will learn |
|---|------|---------------------|
| 1 | `01_html_basics.html` | Document structure, headings, paragraphs, comments |
| 2 | `02_text_links_images.html` | Text formatting, lists, links, images |
| 3 | `03_tables.html` | Tables: headers, colspan, rowspan |
| 4 | `04_forms.html` | Forms: inputs, labels, select, textarea, buttons |
| 5 | `05_semantic_and_media.html` | Semantic tags, audio, video, iframes |
| 6 | `06_css_basics.html` | Selectors, colors, units, ways to add CSS |
| 7 | `07_box_model.html` | Margin, border, padding, box-sizing |
| 8 | `08_flexbox.html` | Flexible one-dimensional layouts |
| 9 | `09_grid.html` | Two-dimensional grid layouts |
| 10 | `10_positioning.html` | static, relative, absolute, fixed, sticky, z-index |
| 11 | `11_responsive_design.html` | Media queries, mobile-first, responsive units |
| 12 | `12_transitions_animations.html` | Transitions, transforms, keyframe animations |
| 13 | `13_project_profile_card.html` | Project: profile card |
| 14 | `14_project_landing_page.html` | Project: responsive landing page |
| 15 | `15_exercises.md` | Practice tasks with expected results |

## How to learn from this repo

1. Go in order — each file builds on the previous one.
2. Open each file in your browser **and** in a code editor side by side.
3. Read the comments, then change values (colors, sizes, text) and refresh to see what happens.
4. After each file, do the matching exercises in `15_exercises.md`.
5. Finish the two projects, then rebuild them from scratch without looking.

You need nothing installed — just a browser and a text editor (VS Code recommended).
